# Syeda Sanjida Malik — Developer Portfolio

Responsive portfolio built with plain HTML, CSS and JavaScript.

## Run in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension (recommended).
3. Right-click `index.html` → **Open with Live Server**.

No npm or build step is required.

## Files

- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — navigation, scroll progress and reveal animations
- `assets/profile.jpg` — professional photo
- `assets/Syeda_Sanjida_Malik_CV.pdf` — CV download (if included)
